# Agent Hub

회사 공용 PC 한 대에 Claude, Codex, Gemini 에이전트를 띄워 두고 같이 쓰는 호스트입니다.

사람은 메인 에이전트에게 일을 맡기고, 메인은 그 일을 나눠 하위 에이전트들에게 동시에 맡긴 뒤 결과를 모아 보고합니다. 화면은 Claude 앱처럼 왼쪽 작업 목록, 가운데 대화, 오른쪽 작업 정보로 되어 있습니다.

## 할 수 있는 것

- **메인과 하위 에이전트**: 메인이 `clink` 로 Claude, Codex, Gemini 에게 일을 나눠 맡깁니다. 여러 개를 동시에 돌리고, 위험한 행동은 허용/거부 버튼으로 막습니다.
- **에이전트와 프리셋**: 역할, AI, 모델, 쓸 수 있는 툴과 스킬을 에이전트로 저장해 두고 `@이름` 으로 부릅니다. 프리셋에는 작업 폴더와 작업 방식 지침을 담습니다.
- **포크, 분담, 복사**: 앞 대화를 이어받아 새 작업을 만듭니다.
  - 포크: 다른 길을 따로 시험합니다. 포크에서 한 일만 원본으로 공유됩니다.
  - 분담: 같은 일을 나눠 맡습니다. 원본과 분담이 서로 한 일을 주고받습니다.
  - 복사: 공유 없는 따로 된 사본입니다.
- **진행 상황과 알림**: 왼쪽 작업 목록에 일하는 작업이 지금 하는 일과 경과 시간을 보여 줍니다. 끝났는데 아직 안 본 답은 점으로, 탭 제목에는 확인할 작업 수로 표시합니다. 다른 작업을 보고 있거나 창이 가려져 있을 때 일이 끝나거나 승인이 필요하면 브라우저 알림을 띄웁니다. 알림은 이 PC 화면(127.0.0.1)에서만 뜨고, 처음 일을 맡길 때 허락을 묻습니다.
- **예약**: 정한 시각(한 번, 매일, 평일, 매주)이나 간격(N분·N시간마다)으로 지시를 보냅니다.
- **에이전트 설정 바꾸기**: 작업 중간에 에이전트, AI, 모델을 바꿔도 앞 대화를 이어받습니다.
- **권한 묻지 않기**: 켜 두면 에이전트가 도구를 허용 버튼 없이 바로 씁니다. 에이전트나 작업마다 정하거나, 설정 → 연동의 "권한 묻지 않기" 스위치로 모든 작업에 한 번에 켭니다.
- **화면 제어**: 이 PC 화면을 브라우저에서 보고 마우스와 키보드로 조작합니다. 메인 에이전트도 화면을 보고 누르고 입력할 수 있습니다.
- **원격 접속**: 같은 사무실 네트워크의 PC나 폰에서 이 PC 앞과 똑같이 씁니다.
- **Claude Code 에서 이어 하기**: 이 PC 에서 쓰던 Claude Code 세션을 가져와 그 대화에 이어서 합니다.
- **연동**: AI 마다 로그인 또는 API 키, GitHub 회사 계정 로그인, 없는 CLI 설치.
- **자동 업데이트**: 매일 이 레포를 확인해 새 버전을 받고 저절로 다시 켭니다.

## 필요한 것

- [Node.js](https://nodejs.org) 22.6 이상 (다른 패키지는 필요 없습니다)
- git
- Windows, macOS, 리눅스(Ubuntu 등) 어느 것이든

Claude, Codex, Gemini CLI 는 미리 깔지 않아도 됩니다. 없으면 연동 화면에 "설치" 버튼이 나옵니다.

## 바로 실행

폴더를 받은 뒤 운영체제에 맞는 파일을 더블클릭합니다.

| | 실행 파일 |
|---|---|
| Windows | `start-windows.cmd` |
| macOS | `start-mac.command` |
| 리눅스 | `start-linux.sh` (파일 관리자에서 "실행", 또는 터미널에서 `./start-linux.sh`) |

꺼져 있으면 뒤에서 켜고 브라우저로 http://127.0.0.1:4317 을 엽니다. 이미 켜져 있으면 브라우저만 엽니다. Node.js 가 없거나 오래됐으면 설치 페이지를 알려 줍니다.

## 설치 (아이콘과 자동 시작)

```bash
git clone https://github.com/firstfuturevision/FutureVision-AgentHub agent-hub
cd agent-hub
npm run setup
```

`npm run setup` 은 바탕화면에 "Agent Hub" 아이콘을 만들고, 로그인하면 저절로 켜지게 합니다. 관리자 권한은 필요 없습니다.

| | 시작 아이콘 | 로그인하면 자동 시작 |
|---|---|---|
| Windows | 바탕화면, 시작 메뉴 | 시작프로그램 |
| macOS | 바탕화면 `Agent Hub.command` | LaunchAgent |
| 리눅스 | 앱 목록, 바탕화면 | `~/.config/autostart` |

아이콘을 누르면 꺼져 있을 때만 뒤에서 켜고 브라우저로 http://127.0.0.1:4317 을 엽니다.

## 켜고 끄기

```bash
npm start        # 이 터미널 창에서 켜기 (창을 닫으면 꺼짐)
npm run stop     # 뒤에서 도는 것 끄기
npm run setup -- --remove   # 시작 아이콘과 자동 시작 지우기
```

화면은 기본으로 이 PC 에서만 열립니다(127.0.0.1). 같은 사무실 네트워크에서 쓰려면 연동의 **원격 접속**을 켭니다.

## 처음 설정

왼쪽 **설정 → 연동** 에서 합니다.

1. **AI 로그인**: Claude, Codex, Gemini 마다 로그인하거나 API 키를 넣습니다. 공용 PC 이므로 개인 구독 대신 회사 계정이나 API 키를 씁니다.
   - **기본 로그인**은 에이전트를 고르지 않은 작업에, **에이전트 로그인**은 에이전트를 골라 시작한 작업에 쓰입니다.
   - API 키는 이 PC 의 `data/auth.json` 에만 저장되고 화면에는 다시 나오지 않습니다.
   - Claude 모델 목록은 이 PC 의 Claude Code CLI 가 아는 모델로 저절로 채워집니다. 새 모델이 안 보이면 CLI 가 예전 버전인 것이라, Claude 칸의 "CLI 업데이트"를 누릅니다.
2. **GitHub**: "로그인"을 누르고 화면에 뜬 코드를 승인 페이지에 넣습니다. 에이전트가 git 과 gh 를 이 계정으로 씁니다.
3. **업데이트**: 자동(매일 새벽 4시에 받아서 다시 켬) 또는 수동(알림만)을 고릅니다. 업데이트 버튼으로 받으면 어떻게 켰든 Agent Hub 가 저절로 다시 켜지고, 열려 있던 화면도 저절로 새로 고쳐집니다. 진행 중인 작업이 있으면 끝난 뒤에 켜고, 기다리는 동안 "지금 다시 켜기"로 바로 켤 수 있습니다.
4. **원격 접속**: 켜면 같은 사무실 네트워크의 PC나 폰 브라우저에서 화면에 나온 주소(예: `http://192.168.0.12:4319`)로 들어옵니다. 비밀번호는 없고, 들어온 사람은 이 PC 앞과 똑같이 씁니다. 켜 두면 이 PC 화면도 그 주소로 열려서 주소창 주소를 그대로 알려 주면 됩니다. 처음 켤 때 Windows 방화벽 창이 뜨면 개인 네트워크만 허용합니다.
5. **권한 묻지 않기**: 켜면 모든 작업이 파일 읽기·수정·Bash 를 허용 버튼 없이 바로 합니다. 켜는 순간 기다리던 요청도 허용합니다. 작업마다 켜려면 작업 정보 → 지침 → 바꾸기.
6. **자동 실행**: 켜면 이 PC 에 로그인할 때 Agent Hub 를 뒤에서 켭니다(다음 로그인부터). `npm run setup` 이 만든 자동 시작도 여기서 끕니다.
7. **공유**: 회사 GitHub 레포(예: `firstfuturevision/agent-hub-shared`)를 넣으면 프리셋, 에이전트, 스킬, 툴을 PC 끼리 주고받습니다.
   - 종류마다 켜고 끕니다. 켜고 15초 뒤와 6시간마다, 또는 "지금 받기"로 받습니다.
   - 받은 것은 목록에 "공유"로 보이고 이 PC 에서 고칠 수 없습니다. 고치려면 "복사"합니다. 같은 이름의 내 것은 "(내 것)"을 붙여 남깁니다.
   - 내 것의 "올리기"로 레포에 올립니다(쓰기 권한이 있는 GitHub 계정). 키·토큰이 들어 있으면 올리지 않습니다.
   - 메인에게 "이 프리셋 공유 레포에 올려줘"라고 해도 됩니다(승인 카드가 뜬 뒤 올림). 프리셋도 대화로 만들 수 있습니다.

## 화면 제어

왼쪽 위 Agent Hub 옆 모니터 버튼을 누르고 오른쪽 위 스위치로 켭니다(기본 꺼짐). 원격 접속과 함께 켜면 다른 PC나 폰에서도 이 PC 화면을 다룹니다.

- 컴퓨터에서는 마우스를 그대로 쓰고, 화면을 한 번 누른 뒤 치는 키가 이 PC 로 갑니다. 한글은 이 PC 의 입력기가 조합합니다.
- 폰에서는 톡 = 클릭, 길게 = 오른쪽 클릭, 두 손가락 = 스크롤. 글자는 아래 칸에 써서 보냅니다.
- 누가 보고 있으면 이 PC 화면 위에 표시가 뜹니다(GNOME 은 위쪽 표시줄의 화면 공유 표시).
- **에이전트가 다루기**: 화면 제어가 켜져 있으면 메인 에이전트가 `screen_view`(보기), `screen_click`·`screen_drag`·`screen_scroll`(마우스), `screen_type`·`screen_key`(글자·단축키)로 이 PC 의 프로그램을 직접 다룹니다. "메모장 열어서 이거 적어 줘"처럼 시키면 됩니다. 한 번 할 때마다 바뀐 화면을 보고 확인합니다.
- **채팅에 그림 띄우기**: "화면 찍어서 보여줘", "게임 스샷 공유해줘"라고 하면 메인 에이전트가 `show_image` 로 지금 화면(화면 제어가 켜져 있을 때)이나 그림 파일(png·jpg·gif·webp)을 채팅에 띄웁니다. 누르면 새 탭에서 원래 크기로 열립니다. 그림은 `data/images/` 에 남아 다시 켜도 보입니다.

| | 방식 | 안 되는 것 |
|---|---|---|
| Windows | 기본으로 들어 있는 C# 컴파일러로 도우미를 만들어 씁니다 | 관리자 확인 창, 잠금 화면(PC 앞에서 누르기) |
| 리눅스 X11 | Python 3 와 X11 기본 라이브러리 | |
| 리눅스 GNOME Wayland (Ubuntu 26.04 등) | GNOME 원격 데스크톱(RDP)을 Agent Hub 가 직접 켜서 붙습니다. 허용 창도 sudo 도 없습니다 | GNOME 이 아닌 Wayland(KDE 등) |

- 따로 설치할 것은 없습니다.
- 리눅스 화면이 잠겨 있으면 Agent Hub 가 잠금을 풀고 들어가고, 다 보고 나면(1분 동안 안 보거나 화면 제어를 끄면) 다시 잠급니다.

## 쓰는 법

1. **새 작업**에서 프리셋과 메인 에이전트를 고르고 할 일을 입력합니다.
2. 메인이 하위 에이전트에게 맡긴 일은 대화 속 카드로 보이고, 오른쪽 작업 정보의 **백그라운드**와 **하위 작업**에도 나옵니다.
3. 메인이 결과를 확인해 보고합니다.

입력창에서:

- `@` 에이전트 부르기
- 하던 일은 입력창의 ■ 로 멈춥니다. 작업은 대기로 남고 바로 이어서 지시할 수 있습니다. 호스트를 다시 켜도 지우기 전까지 이어서 합니다.
- 새 작업 화면의 **Claude Code 에서 이어 하기**: 이 PC 에서 직접 연 Claude Code 세션(터미널·데스크톱 앱)을 골라 같은 폴더에서 그 대화에 이어서 합니다. FV 대시보드에는 나오지 않습니다. "사용 중"은 방금까지 다른 창에서 쓰던 세션이라, 원래 창을 닫고 이어 가야 대화가 갈라지지 않습니다.
- `/` 명령 (새 작업, 멈추기, 에이전트 만들기, 설정 열기 등)
- 파일은 붙여넣기, 끌어다 놓기, ＋ 버튼으로 첨부

작업 목록의 ⋯ 메뉴: 이름 바꾸기, 포크, 분담, 복사, 삭제.

오른쪽 **작업 정보**(대화 오른쪽 위 버튼)는 두 칸입니다.

**컨텍스트**: 에이전트가 지금 보고 있는 것

- **사용량**: 컨텍스트를 얼마나 썼는지 (Claude, 그리고 사용량을 알려 주는 CLI)
- **이어받은 내용**: 앞 대화, 포크와 분담에서 받은 공유. 아직 안 넣은 것은 "다음 지시에"로 표시
- **에이전트 설정**: 지침, 스킬, 연결 폴더, 허용 에이전트와 툴. "바꾸기"로 에이전트와 모델을 바꿉니다.

**세션**: 이 작업의 진행

- **연결된 세션**: 포크와 분담, 그 원본
- **백그라운드**: 지금 일하는 하위 에이전트
- **하위 작업**: 끝난 하위 에이전트 일
- **예약**: 정한 시각의 지시

기능마다 실제로 어떻게 움직이는지는 [docs/GUIDE.md](docs/GUIDE.md), 설계와 결정 근거는 [docs/DESIGN.md](docs/DESIGN.md) 에 있습니다.

## 설정 파일

필요할 때만 `config.json` 을 만듭니다. 없으면 기본값으로 돕니다.

```json
{
  "port": 4317,
  "workspaceRoot": "D:/agent-work",
  "mainAgent": "claude"
}
```

- `workspaceRoot`: 에이전트가 일하는 폴더의 뿌리. 기본은 `./workspace`
- `updateRepo`: 업데이트를 받을 레포. 기본은 이 레포

## 안전

- 화면과 서버는 기본으로 이 PC 안(127.0.0.1)에서만 열립니다.
- 원격 접속을 켜면 같은 사무실 네트워크(사설 주소)의 누구나 비밀번호 없이 이 PC 앞과 똑같은 권한(설정·키 바꾸기, 권한 묻지 않기, 뿌리 밖 폴더, 터미널)으로 씁니다. 인터넷에는 열리지 않고, 주소창 주소는 이 PC 의 주소나 컴퓨터 이름이어야 합니다(남의 사이트가 이 PC 를 몰래 부르는 것 차단). 손님 Wi-Fi 처럼 모르는 사람이 붙는 네트워크에서는 켜지 마세요.
- 화면 제어를 켜면 원격 접속으로 들어온 누구나 이 PC 화면을 보고 조작합니다. 리눅스 GNOME 에서는 잠긴 화면도 풀고 들어갑니다(보는 동안 그 PC 앞에서도 잠금 없이 쓸 수 있음). 따로 켜고 끄며 기본은 꺼짐. 보는 동안 이 PC 화면 위에 표시가 뜹니다. 켜져 있으면 메인 에이전트도 화면을 다룰 수 있습니다(권한 묻지 않기가 꺼져 있으면 누를 때마다 허용을 묻습니다).
- 에이전트는 일반 사용자 권한으로 돕니다. 관리자로 실행하면 화면에 경고가 뜹니다.
- 도구를 쓸 때는 허용 버튼을 거칩니다. "권한 묻지 않기"는 이 PC 화면과 원격 접속에서만 켤 수 있고(대시보드에서는 끄기만), 켜진 작업은 작업 정보에 빨간 글씨로 표시됩니다.
- 키, 로그인 정보, 작업 기록은 `data/` 에만 있고 레포에 올라가지 않습니다.
- 에이전트를 골라 시작한 작업은 Agent Hub 전용 프로필로 떠서, 이 PC 사람의 개인 설정과 스킬을 읽지 않습니다.
- 작업 폴더 뿌리 밖의 폴더는 PC 앞에서 직접 골라야 연결되고, `data/` 가 든 폴더는 연결할 수 없습니다.
- 업데이트는 앞으로 감기만 합니다. 이 PC 에서 고친 파일이 있으면 덮어쓰지 않고 멈춥니다.
